# Able To Love — Growth & Marketing

Everything needed to launch and grow **Able To Love**, the dating app built for and with the disability community. This directory is the single source of truth for how we talk about the app, where we show up, and what we ship.

## What's here

| File | Purpose |
|---|---|
| `01-campaign-strategy.md` | Positioning, audience, goals, funnel, budget, and the metrics we hold ourselves to |
| `02-messaging-guide.md` | Brand voice, taglines, and the disability-affirming language rules every asset must follow |
| `03-content-calendar.md` | A 30-day launch calendar mapped to channels and themes |
| `04-social-content-pack.md` | Ready-to-post captions for Instagram, TikTok, X, and YouTube |
| `05-aso-and-press-kit.md` | App Store / Play Store copy, keywords, and a press/launch kit |
| `landing-page/index.html` | Self-contained waitlist landing page — deploy anywhere static |

## The one rule that governs all of it

We are marketing a product for a community that has been talked *about* far more often than talked *with*, and marketed *to* with pity far more often than with respect. Every asset here leads with agency, warmth, and normalcy — never inspiration-porn, never pity, never "despite." If a piece of copy would make a disabled person cringe, it does not ship. See `02-messaging-guide.md`.

## How to use the social-media-bot with this campaign

The repo already contains `social-media-bot/`, an automation engine for scheduling and publishing. A niche configuration tuned for Able To Love lives at `social-media-bot/config/abletolove.niche.json`. Load it in the setup wizard (or seed it directly) so trend discovery and content generation stay on-brand and inside the guardrails in the messaging guide.

> Automation amplifies reach; it does not replace judgment. Keep the "flagged replies for review" queue staffed by a human — community trust is the entire moat of a dating app.
