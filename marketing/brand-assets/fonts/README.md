# Overlay font (the Able2Love logo font)

Drop the logo's font file here as `logo.ttf` (or `.otf`). Every text overlay
baked onto or rendered over a picture (eye-bar phrases, profile name, reveal
copy) will use it automatically. If no file is here, the code falls back to
DejaVu Sans Bold.

This is for ON-IMAGE overlays only — not the in-app UI.
